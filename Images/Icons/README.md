# App icon assets

The four full-size palettes are `amethyst`, `sapphire`, `emerald`, and `pearl-rose`. Each has an opaque 1024×1024 PNG and a matching `-transparent` PNG. The opaque versions are the intended starting point for future native iOS alternate icons; they are not yet wired to an iOS app.

The website uses the transparent amethyst artwork. Files prefixed `web-` are close-cropped, resized derivatives for browser tabs, the web manifest, and the Apple touch icon. The source variants remain full-size so they can be prepared as layers for Apple's Icon Composer later.
